# ОСНОВА — сайт строительной компании

Адаптивный демонстрационный сайт на русском языке: услуги, галерея концепций, подход к работе, калькулятор бюджета и подготовка заявки для скачивания.

## Локальный запуск

Нужен Python 3, установка зависимостей не требуется:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Сайт работает без сборки. Основные файлы:

- `index.html` — содержание и разметка;
- `styles.css` — оформление и адаптация для телефона;
- `app.js` — меню, проекты, калькулятор и скачивание заявки;
- `assets/` — локальные изображения, шрифт и favicon.

## Публикация

Для GitHub Pages выберите в Settings → Pages: **Deploy from a branch**, ветка **main**, папка **/ (root)**. Файл `.nojekyll` отключает обработку Jekyll. Изменения ветки `main` публикуются автоматически.

Адрес после включения Pages: https://mawrikborug.github.io/Osnova-stroy/

## Перед использованием для реальной компании

Замените демонстрационное название и концепции реальными данными, добавьте контакты и подключите обработку заявок. Сейчас форма создаёт текстовый файл локально в браузере: данные не отправляются на сервер и не сохраняются между посещениями. При изменении формы подготовленная заявка сбрасывается.

Калькулятор использует условные ставки: каркас — 45 000 ₽/м², газобетон — 60 000 ₽/м², кирпич — 75 000 ₽/м². Чистовая отделка добавляет 20 000 ₽/м². Диапазон составляет ±10%. Эти значения служат демонстрацией и не являются коммерческим предложением.
